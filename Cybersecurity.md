🥇 LEVEL 1 — Basics & Foundations

Before hacking or security tools, you need strong fundamentals:

Learn:

Networking basics

TCP/IP, UDP, HTTP, HTTPS

Ports, protocols, IP addresses

DNS, DHCP, NAT

Operating systems

Windows, Linux (Kali Linux recommended)

File systems, permissions, shell commands

Programming

Python → for scripting tools & automation

Bash scripting → Linux command automation

Java/JavaScript → web application understanding

Cybersecurity concepts

Confidentiality, Integrity, Availability (CIA triad)

Threats, attacks, vulnerabilities

Project / Practice:

Set up a local Linux VM

Ping, traceroute, basic network scanning

Learn how attacks happen:

Web Security:

Common vulnerabilities:

SQL Injection

XSS (Cross-site Scripting)

CSRF (Cross-site Request Forgery)

File upload vulnerabilities

Tools:

Burp Suite

OWASP ZAP

System Security:

Password security & hashing

File permissions

Privilege escalation basics

Practice:

Build a vulnerable web app (like DVWA / OWASP WebGoat)

Learn to scan and exploit networks safely:

Nmap → network scanning

Wireshark → packet sniffing

Metasploit → exploit testing

VPN / Proxy tools

Practice:

Scan your home network for open ports

Capture network packets

Try local penetration testing in virtual lab
